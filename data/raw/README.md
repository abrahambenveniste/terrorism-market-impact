# Raw source files (local only)

Keep downloaded GTD, market-provider, and other raw source files here only when you are entitled to hold them locally. This directory is ignored by Git. Never commit raw files, source narratives, API credentials, or provider exports unless the exact license expressly permits public redistribution and the project records that permission.

Record source name, release/version, retrieval date, exact query or export filters, license/terms URL and review date, and SHA-256 digest in [`../source_manifest.csv`](../source_manifest.csv). Do not change an original source file; perform transformations into separate derived files.
