# Normalized data dictionary

These are target fields for the pipeline. Source-specific fields must be retained in an archival local extract or a documented crosswalk so the transformations can be audited. Do not publish restricted raw records.

## Event table: one row per source incident

| Field | Type | Meaning |
|---|---|---|
| `source_name` | string | e.g. `GTD`; do not merge source taxonomies without a source flag. |
| `source_version` | string | Release name/date or API retrieval version. |
| `source_event_id` | string | Stable source event identifier. |
| `event_date` | date | Reported local calendar date. |
| `country_iso3` | string | Event-location country code. |
| `city` | string / missing | Source-reported location, if permitted and available. |
| `latitude`, `longitude` | numeric / missing | Source coordinates; retain precision/uncertainty metadata if present. |
| `gtd_criteria_pass` | boolean / missing | Whether the pre-registered three-criterion rule is met. |
| `doubtterr` | integer / missing | Original uncertainty code; do not erase. |
| `attack_type` | categorical / missing | Source's original category plus a separately documented harmonized category. |
| `nkill`, `nwound` | numeric / missing | Source-reported counts; missing is not zero. |
| `is_suicide`, `multiple` | boolean / missing | Original source indicators where present. |
| `source_record_hash` | string | Optional hash of a locally held restricted row/export, never a replacement for the licensed file. |

## Market table: one row per index session

| Field | Type | Meaning |
|---|---|---|
| `country_iso3` | string | Market country. |
| `session_date` | date | Exchange-local session date for the close. |
| `index_id` | string | Official ticker/ISIN/provider identifier and index variant. |
| `index_level` | numeric | Unrounded close when available; positive and non-missing for a valid session. |
| `currency` | string | Local currency for the domestic benchmark. |
| `return_type` | categorical | `price`, `gross_total_return`, or `net_total_return`; never infer from the index label alone. |
| `provider` | string | Exchange, index administrator, or licensed data vendor. |
| `source_version` | string | Download date, data revision, and source query/filters. |
| `is_official_close` | boolean | Whether the value is an official close rather than an intraday quote or derived proxy. |
| `session_status` | categorical | `open`, `closed`, `suspended`, `missing`, or other documented state. |

Derived fields (returns, event time, abnormal returns, CAR, standardized CAR, event-window volatility) should be generated by code and written to derived outputs with a code version and source manifest reference.
